# 연구실 현황판 - 에셋 계획서

## 프로젝트 요약

| 항목 | 내용 |
|------|------|
| 페이지 | `/lab-status` (별도 페이지) |
| 표시 대상 | 모든 승인 멤버 |
| 접근 권한 | 로그인 멤버만 열람 가능 |
| 상태 변경 | 본인 + 관리자 |
| 렌더링 | HTML/CSS + 이미지 (개별 타일/가구 조립 방식) |
| 좌석 | 멤버별 고정 좌석 (관리자 지정) |
| 캐릭터 | 멤버별 커스텀 픽셀 캐릭터 (1장) |
| 애니메이션 | CSS 전체 변환 (호흡, 흔들림, 끄덕 등) — 스프라이트 없음 |

## 1. 바닥 타일

| 항목 | 내용 |
|------|------|
| 파일 | `tiles/floor.png` |
| 크기 | **32 x 32px** 또는 **64 x 64px** (1타일) |
| 스타일 | 픽셀 아트, 연구실 바닥 느낌 |
| 사용 | `background-repeat: repeat`로 전체 바닥에 깔기 |
| 배경색 | 밝은 회색/베이지 계열 |

## 2. 가구

CSS `position: absolute`로 배치도에 맞춰 좌표 지정합니다.

| 파일 | 권장 크기 | 설명 |
|------|----------|------|
| `furniture/desk.png` | 100 x 50px | 모니터 올려진 책상 (3/4뷰) |
| `furniture/desk-empty.png` | 100 x 50px | 모니터 꺼진 빈 책상 |
| `furniture/monitor-on.png` | 40 x 30px | 모니터 켜진 상태 (화면 빛남) |
| `furniture/monitor-off.png` | 40 x 30px | 모니터 꺼진 상태 |
| `furniture/chair.png` | 30 x 30px | 사무용 의자 |
| `furniture/meeting-table.png` | 140 x 100px | 회의 테이블 |

> 크기는 자유롭게 조절 가능. 비율만 맞으면 CSS로 리사이징합니다.
> 모두 **투명 배경 PNG**.

## 5. 캐릭터 (핵심)

### 변경: 스프라이트 시트 → 단일 이미지

테스트 결과 **1장의 이미지에 CSS 애니메이션만으로 충분한 표현**이 가능했습니다.
스프라이트 시트는 불필요합니다.

### 멤버당 필요한 그림: 1장

| 항목 | 내용 |
|------|------|
| 파일 | `characters/{멤버이름}.png` |
| 크기 | 자유 (권장 **80~120px 높이**) |
| 스타일 | 픽셀 아트, 정면 또는 3/4뷰, 서 있는 기본 자세 |
| 배경 | **투명 (PNG)** |
| 구분 | 멤버별로 옷 색상, 머리 스타일, 안경 등으로 구분 |

### CSS 애니메이션으로 구현되는 동작

이미지 1장을 CSS `transform` + `filter`로 움직입니다.

| 상태 | 애니메이션 | 추가 요소 |
|------|----------|----------|
| 🧑‍💻 연구 중 | 호흡(위아래 3px) + 미세 기울기(±0.5°) | 말풍선 "코딩 중..." |
| 🔴 집중 모드 | 좌우 흔들림(±2px) + 빨간 글로우 | DND 뱃지 깜빡 |
| 🤝 회의 중 | 고개 끄덕(아래 3px 반복) | 말풍선 "넵 👍" |
| 🍽️ 식사 중 | 없음 (캐릭터 반투명 + 회색) | 🍽️ 아이콘 |
| 🎓 수업 중 | 없음 (캐릭터 반투명 + 회색) | 🎓 아이콘 |
| 🚶 외출 중 | 없음 (캐릭터 반투명 + 회색) | 메모지 이미지 |
| 🏠 퇴근 | 없음 (캐릭터 거의 안 보임) | 🏠 아이콘 |
| 출근 전환 | 아래서 튀어오르며 등장 | 바운스 효과 |
| 퇴근 전환 | 옆으로 사라짐 | 페이드아웃 |

### 폴더 구조 예시 (멤버 6명)
